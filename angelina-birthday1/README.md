# 🎂 С Днём Рождения, Ангелина!

Поздравительный сайт для Ангелины на 25-летие.

## 🌐 Как опубликовать на GitHub Pages:

### Шаг 1: Создайте GitHub аккаунт
1. Перейдите на https://github.com
2. Нажмите "Sign up" и создайте аккаунт (если его нет)

### Шаг 2: Создайте новый репозиторий
1. Войдите в GitHub
2. Нажмите "+" в правом верхнем углу → "New repository"
3. Название: `angelina-birthday` (или любое другое)
4. Сделайте репозиторий **Public** (публичный)
5. Нажмите "Create repository"

### Шаг 3: Загрузите файлы
1. На странице нового репозитория нажмите **"uploading an existing file"**
2. Перетащите ВСЕ файлы из папки `F:\angelina-birthday`:
   - `index.html`
   - Папку `photos` со всеми фотографиями внутри
3. Нажмите "Commit changes"

### Шаг 4: Включите GitHub Pages
1. В репозитории перейдите в **Settings** (Настройки)
2. Слева найдите **Pages**
3. В разделе "Source" выберите **Branch: main** → папка **/root**
4. Нажмите **Save**

### Шаг 5: Получите ссылку
Через 1-2 минуты сайт будет доступен по адресу:
```
https://ваш-ник.github.io/angelina-birthday/
```

Эту ссылку можно открывать на любом устройстве! 🎉
